Overview Why Arch + Hyprland Hardware & Dev Streaming & Editing

Hardware Specs & Development Capabilities

How a Lenovo ThinkPad X13 Gen 1 (Intel Core i5-10310U, Intel UHD Graphics, 15 GiB RAM, 476.9 GiB NVMe) holds up as a daily software engineering workstation.

Machine Overview

Compute & Graphics

Intel Core i5-10310U (4 cores / 8 threads, up to 4.4 GHz boost) paired with CometLake-U GT2 Intel UHD Graphics (mesa, vulkan-intel, intel-media-driver).

Memory & Storage

15 GiB usable RAM plus 4 GiB zram swap on a 476.9 GiB NVMe SSD.

Display & I/O

1920×1080 internal panel (eDP-1) with external DisplayPort/HDMI outputs for docked setups.

Battery Health Note

Design capacity 48.02 Wh (~75% remaining capacity after ~799 cycles)—good for portable sessions; plug into AC for sustained builds or streaming.

Where It Excels

1. Software, Web & Backend Development

  • Full Language Toolchains: Runs Python (uv, ruff, basedpyright), Node.js/TypeScript (npm, tsc), Rust (rust-analyzer), C/C++ (gcc, clang), and Java comfortably.
  • Containers & Services: 15 GiB RAM + 4 GiB zram + NVMe handles local Docker / Docker Compose stacks alongside editors (neovim, VS Code, PyCharm/IDEA) and browser tabs.
  • Ergonomic Tiling: At 1080p, Hyprland splits keep editor, terminal, and browser cleanly tiled without window-chrome waste.

2. Cloud-Backed & Agentic Coding

Lightweight terminals and editors (ghostty, kitty, neovim, VS Code) combined with cloud-hosted AI coding agents get maximum portability and responsiveness without needing local discrete GPU hardware.

3. Linux Engineering & Tooling

Well suited for SSH/remote workflows, API benchmarking (wrk), secret scanning (gitleaks), and Git tooling (lazygit, gh).

Practical Ceilings

  1. Local LLMs / ML Training: Integrated Intel UHD Graphics has no dedicated VRAM or CUDA. Only tiny CPU-quantized models are practical locally.
  2. Heavy Simultaneous VMs / Huge Builds: 4 cores / 8 threads handle typical services smoothly, but spinning up multiple heavy VMs or massive C++/Rust builds alongside heavyweight IDEs and dozens of browser tabs will saturate CPU and RAM.
  3. Modern 3D Gaming & GPU Compute: Fine for 2D, indie, and older titles via vulkan-intel; not built for demanding AAA 3D games or Blender GPU rendering.
